# Website Updates - Dataset Tracking Feature

## Summary

The experiment overview website has been updated to include comprehensive dataset usage tracking and visualization.

## Changes Made

### 1. Updated Hover Information

**Timeline Visualization** (`experiment_timeline.html`)
- Added "Datasets Used" field to hover tooltips
- Shows which datasets and how many crops from each are used in each experiment

**Gantt Chart** (`experiment_gantt.html`)
- Added "Datasets Used" field to hover tooltips
- Provides dataset information alongside training duration and other metrics

### 2. New Dataset Usage Visualization

**New Page**: `dataset_usage.html`

This new interactive visualization includes 4 key charts:

1. **Dataset Usage Frequency (Top 20)**
   - Shows which datasets are used most frequently across all experiments
   - Bar chart of experiment count per dataset

2. **Total Crops per Dataset (Top 20)**
   - Displays how many unique crops exist for each dataset
   - Helps identify datasets with rich annotations

3. **Most Reused Crops (Top 20)**
   - Highlights which specific crops are used across multiple experiments
   - Identifies popular/high-quality training data

4. **Experiments per Dataset Distribution**
   - Histogram showing the distribution of experiment counts across datasets
   - Helps understand data usage patterns

### 3. Updated Landing Page

**Main Page**: `index.html`

Added two new cards to the visualizations section:

1. **🗄️ Dataset Usage**
   - Links to the new dataset usage statistics page
   - Description: "Analyze dataset and crop usage across all experiments"

2. **📋 Data Usage YAML**
   - Links to the detailed YAML file on GitHub
   - Provides access to complete crop-level tracking data

Now the landing page features 6 visualization/data access options:
- Interactive Timeline
- Gantt Chart
- Statistics Dashboard
- **Dataset Usage** (NEW)
- Raw Dataset (CSV)
- **Data Usage YAML** (NEW)

## Data Source

All dataset usage information is extracted from:
- Source: `data/processed/data_usage_overview.yaml`
- Generated by: `scripts/generate_overview_csv.py`
- Contains: Setup → Dataset → Crop mappings

## Technical Details

### Function: `create_dataset_usage_stats()`

Location: `scripts/generate_timeline.py`

**Purpose**: Generate dataset usage statistics from the YAML file

**Output Statistics**:
- Dataset frequency counts
- Unique crops per dataset
- Crop reuse patterns
- Distribution analysis

**Implementation**:
- Reads `data_usage_overview.yaml`
- Calculates aggregated statistics
- Creates 4 subplot visualizations using Plotly
- Exports to `dataset_usage.html`

### Updated Functions

1. **`create_timeline_graph()`**
   - Added "Datasets Used" to customdata array
   - Updated hovertemplate to display dataset information

2. **`create_gantt_chart()`**
   - Added datasets_str variable extraction
   - Updated hovertemplate to include dataset usage

## Usage

### Generate/Update Website

```bash
cd /groups/cellmap/cellmap/zouinkhim/exp-overview
python3 scripts/generate_timeline.py
```

This will:
1. Read the CSV with dataset information
2. Load the YAML for detailed statistics
3. Generate all visualization HTML files
4. Update the landing page with new links

### View Locally

Open any of the HTML files in a web browser:
```bash
open output/visualizations/index.html
```

### Deploy to GitHub Pages

The files in `output/visualizations/` are ready for GitHub Pages deployment. Simply commit and push to trigger the deployment workflow.
